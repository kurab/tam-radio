ご利用にあたって

Tám Radio（タムラジオ）は、ベトナムで話題になっていることを毎朝お届けする、個人の非営利の番組です。聞く前に、次のことをご確認ください。

1. この番組がお約束しないこと

  • モテることは保証しません。「モテるベトナムの話題」は、会話のきっかけになればという番組の名前です。聞いた結果、モテるようになることをお約束するものではありません。
  • 話題はベトナムの報道や SNS をもとに選び、台本は AI を使って日本語にまとめています。声は音声合成、キャラクターは AI で生成したものです。
  • 人物についての話題は、元の報道を紹介したものです。番組がその人を評価したり、内容を事実だと断定したりするものではありません。
  • 締めの「今日運勢の良い干支」には根拠がありません。楽しむためのものです。
  • 各回は、配信から 14 日間お聞きいただけます。過ぎると音声と共有ページは消え、古いリンクは開けなくなります。
  • 内容の正確さや新しさには気をつけていますが、保証はできません。まとめる途中で、元の記事と違う内容になっていることもあります。大事なことは、元の記事でご確認ください。
  • この番組の内容を使ったことで生じた損害について、番組は責任を負いません。
  • リンク先のサイトの内容は、それぞれのサイトの責任で公開されています。

2. トピックの記事と画像

  • トピック欄に出ている記事の見出しと画像の権利は、それぞれの提供元（記事を掲載しているサイト）にあります。
  • 画像は、記事へのリンクと一緒に、提供元のサーバーから直接表示しています。この番組が画像を保存したり、転載したりはしていません。
  • 元の記事の権利も、それぞれの提供元にあります。
  • 権利をお持ちの方で、表示をやめてほしい場合は、お問い合わせの窓口からお知らせください。確認のうえ対応します。

3. この番組の文章・音声・画像の利用

番組の台本、字幕、音声、キャラクターの画像、ロゴなど、この番組が作ったものの権利は、番組の運営者（kurab）にあります。

4. 情報の扱い

  • アクセス解析、広告、Cookie は使っていません。
  • 再生速度、音量、言語、天気の場所は、お使いのブラウザの中に保存します（ローカルストレージ）。番組のサーバーには送りません。
  • 天気で「現在地にする」を選んだときだけ、ブラウザが位置情報の利用を確認します。許可すると、緯度・経度を約 1 km の単位に丸めて、天気予報の Open-Meteo に送ります。丸めた位置は、ブラウザの中に保存します。
  • トピック欄の画像は、提供元のサイトから読み込みます。そのため、提供元のサイトには、画像が表示されたことが伝わります。
  • このサイトは GitHub Pages で公開しています。アクセスの記録は GitHub が扱います（GitHub のプライバシーに関する声明）。
